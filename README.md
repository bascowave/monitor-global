# Monitor global de incidentes

Mostra apagões e ciberataques com fonte e data, em pt, en e es. Tokens visuais em `public/styles.css`, extraídos da referência em 05/11/2026.

## Uso local

    npm run ingest   # coleta as fontes e grava data/incidents.json
    npm start        # http://localhost:3000

## Fontes

Lista e licenças em `../PROPOSTA-FONTES.md`. No MVP só a CISA KEV está ativa. ENTSO-E (precisa de token), ONS e ODIN estão pendentes.

## Deploy

Não publicado. Criar o app na Coolify, o domínio e o DNS exigem autorização explícita.
